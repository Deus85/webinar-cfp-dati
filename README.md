# webinar-cfp-dati

Elenco pubblico dei **webinar gratuiti con CFP per ingegneri**, aggiornato automaticamente ogni 6 ore.

- `webinar.json` — l'elenco letto dall'app *Webinar CFP*

Contiene solo informazioni pubbliche (titolo, data, CFP, link alla pagina ufficiale dell'organizzatore).
L'iscrizione ai webinar avviene sempre sul sito dell'organizzatore.
